Solution. Concentrate workspace metadata, notes, generated VS Code workspace files, and scaffold repair inside one deep Workspace ledger module.

Problem. Agent behavior is a product interface, but the same workflow rules appear in several files with no single module owning drift.

Solution. Treat the agent workflow contract as a deep module: one canonical contract, with README, skill instructions, prompts, and self-check expectations generated or checked against it.

  • locality: agent rules concentrate
  • leverage: docs stay aligned
  • tests catch contract drift

Top recommendation

Start with Collapse cleanup safety into one module: it is the highest-risk workflow, the current shallow functions repeat safety knowledge, and the self-checks already give a strong command-level test surface.
